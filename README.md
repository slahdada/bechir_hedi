# bechir_hedi

Petit projet web contenant une interface simple en HTML, CSS et JavaScript.

## Fichiers
- `index.html` : structure de la page
- `styles.css` : mise en forme
- `app.js` : logique JavaScript

## Installation
- Cloner le dépôt :
  ```bash
  git clone https://github.com/slahdada/bechir_hedi.git
  ```
- Ouvrir le dossier du projet.
- Lancer `index.html` dans un navigateur.
